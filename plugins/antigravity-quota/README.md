# Antigravity Quota (`bb-plugin-antigravity-quota`)

Плагин BB для раздельного учёта личного расхода квоты **Google Antigravity** (в BB) и расхода остальных устройств/членов семьи за **5 часов** и **неделю**.

Встраивается прямо в карточку и tooltip **Google Antigravity** плагина `usage-rings` (без лишней иконки в левом рейле):
- в tooltip и под использованными окнами карточки показывает компактную строку `Я: X% · Семья: Y%`;
- в шапке карточки рядом с кнопкой обновления добавляет иконку графика, открывающую модальное окно с разбивкой по текущему 5-часовику, текущей неделе, расходом по дням (14 дней) и списком последних ходов в BB.

## Как работает

- На хосте читает квоту через `agy --print /usage --output-format json` (`remaining_fraction` с точностью до `0.0001%` и `reset_time`).
- **После завершения хода в BB (`thread.idle` / `thread.failed`)** дельта записывается в **«Я (BB)»** и привязывается к треду.
- **Каждые 2 минуты** в простое (когда нет активных ходов и прошло ≥30 с после завершения хода) фоновое расписание снимает снимок: падение квоты в простое записывается в **«Остальные (семья)»**, а сброс окна автоматически архивируется.
- Уже потраченный до установки плагина процент фиксируется как **«До начала учёта»**, чтобы не искажать доли «Я / Семья». После сброса окна учёт начинается с `0%`.

## Установка

```sh
bb plugin install git:https://github.com/deicer/bb-plugins.git@main --plugin antigravity-quota
```

Из локального каталога:

```sh
bb plugin install ./plugins/antigravity-quota
```

## Команды CLI

```sh
bb antigravity-quota status
bb antigravity-quota refresh
bb antigravity-quota reset
```
